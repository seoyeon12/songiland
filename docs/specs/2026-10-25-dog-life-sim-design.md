# 견생극장 기획서

> 상태: 확정 · 2026-10-25 · 이름 "견생극장", 앱 `apps/dog`, 주소 `dog.arosys.kr` · 1~4단계 완료, 5단계(공유 카드·지난 견생·사건 80개) 진행
>
> 참고작: [1 in 8 Billion(80억 분의 1)](https://1in8b.life/ko/). 무작위로 태어난 한 사람의
> 일생을 사는 시뮬레이션이다. 이 기획은 그 구조를 "견주가 되어 강아지 한 마리의 일생을
> 함께하는" 게임으로 옮긴다.

## 1. 한 줄 소개

어느 날 운명처럼 만난 강아지와 무지개다리까지 함께하는 10~15분짜리 견생 시뮬레이션.
견종도, 만나는 방법도, 이번 판의 이야기 흐름도 매번 무작위다.

## 2. 확정된 결정 (2026-10-25 개발자 답변)

| 항목 | 결정 |
| ---- | ---- |
| 시점 | **견주 시점.** 시간은 자동으로 흐르고, 중요한 순간에 견주가 선택한다. |
| 톤 | **판마다 무작위.** 유쾌하다 뭉클, 끝까지 유쾌, 잔잔하고 뭉클, 뭉클하다 유쾌 등. |
| 금지 | **파양·유기·학대·방치는 선택지로 절대 나오지 않는다.** |
| 다견가정 | **견생 중간에 새 식구를 들일 수 있다.** 최대 3마리. |
| 만남 경로 | **보호소 입양, 시골 마당, 길에서 구조, 지인 분양만.** 펫숍 구매 경로는 없다. |
| 견종 데이터 | **실제 경향 + 밈 견종.** 수명·체급·잘 알려진 건강 경향을 대략 반영한다. |
| 진행 | **자동 진행, 한 판 10~15분.** 일시정지와 배속을 지원한다. |
| 저장·공유 | **이 브라우저에만 저장, 결과는 공유 카드 이미지.** 서버는 두지 않는다. |
| 비주얼 | **글 중심 + 직접 만든 강아지 SVG 하나.** 견종별로 털색·귀·체급만 바꾼다. |
| 견주 이름 | **받지 않는다.** 문장은 강아지 이름과 서술형으로 쓴다(9.2). |
| 안락사 | **노견이고 치료할 수 없는 병일 때만** 선택지로 나온다(7.4). |
| 묘사 수위 | **처음부터 낮게.** "무서운 장면 빼기" 토글은 첫 출시에 두지 않는다. |
| 배경음악 | **첫 출시에는 넣지 않는다.** 나중에 넣을 때는 11.1의 조사 결과와 규칙을 따른다. |
| 이름·주소 | **견생극장**, 앱 폴더 `apps/dog`, 주소 `dog.arosys.kr`. |

## 3. 성공 기준

- 처음 온 사람이 설명 없이 30초 안에 첫 강아지를 만나고 견생을 시작한다.
- 한 판이 기본 속도로 10~15분 안에 끝나고, 끝나면 "한 번 더"를 누르고 싶어진다.
- 같은 견종이라도 판마다 이야기가 다르게 느껴진다(톤 흐름 × 성격 × 사건).
- 어떤 선택을 해도 강아지를 버리거나 해치는 길은 없다. 고민은 늘 "이 아이에게 무엇이
  더 좋을까" 사이에 있다.
- 결말 카드를 이미지로 저장해 SNS에 올릴 수 있다.

## 4. 핵심 흐름

```text
만남 뽑기 → 이름 짓기 → 견생 진행(자동, 1년 ≈ 1분) ⇄ 선택 카드
        → (새 식구 들이기) → 노년 → 무지개다리 → 견생 기록 카드 → 한 번 더
```

### 4.1 만남 뽑기

1in8b가 나라별 출생 통계로 태어날 곳을 뽑듯이, 실제 국내 등록 비율로 만날 견종을 뽑는다.
버튼을 누르면 짧은 연출 뒤에 "오늘 만난 아이" 카드가 나온다.

| 뽑는 것 | 내용 |
| ------- | ---- |
| 견종 | 6장의 견종 표에서 등장 가중치로 뽑는다. 믹스견이 가장 자주 나온다. |
| 만남 경로 | 보호소 입양, 시골 마당에서 태어난 새끼, 길에서 구조, 지인 분양. 견종과 어울리게 뽑는다(시골 마당은 주로 믹스견). |
| 만날 때 나이 | 대부분 아기(2~4개월). 보호소 입양은 성견이나 노견일 수도 있다. 이러면 한 판이 짧아지고 노견 입양 이야기가 열린다. |
| 성격 2가지 | 먹보, 겁쟁이, 인싸, 집순이·집돌이, 장난꾸러기, 껌딱지, 고집쟁이, 느긋함 등에서 2개. 사건과 선택 결과에 영향을 준다. |
| 털색·생김새 | 견종별 후보 안에서 뽑는다. 진도·믹스견은 백구·황구·흑구·바둑이 같은 털색 이름이 붙는다. |
| 이야기 흐름 | 이번 판의 톤 곡선. 플레이어에게는 보이지 않는다(5장). |

강아지 이름만 플레이어가 짓는다. 추천 이름 버튼(콩이, 보리, 초코, 두부, 해피…)도 둔다.
견주 이름은 받지 않는다.
비숑이 나오면 아주 낮은 확률로 "송이"가 추천 이름에 끼는 이스터에그를 둔다.

### 4.2 견생 진행

- 시간 단위는 **한 달**이다. 기본 속도에서 한 달은 약 5초, 1년은 약 1분이다.
- 화면 위에는 일시정지, 1배·2배·4배속이 있다.
- 매달 작은 일상 문장이 견생 로그에 쌓인다. 예: "보리가 산책길에서 처음 고양이를 봤어요."
- 몇 달에 한 번 **선택 카드**가 뜨고 시간이 멈춘다. 선택지는 2~3개다.
- "자동 결정"을 켜면 게임이 성격과 상황에 맞춰 대신 고르고, 플레이어는 지켜본다.
- 결과는 확률로 정해진다. 능력치가 높으면 좋은 결과가 나올 확률이 높아질 뿐, 보장되지는 않는다.

### 4.3 능력치

강아지마다 네 가지, 가정에 하나를 둔다. 모두 0~100이다.

| 능력치 | 대상 | 뜻 | 영향 |
| ------ | ---- | -- | ---- |
| 건강 | 강아지 | 몸 상태 | 병에 걸릴 확률, 노년의 길이 |
| 행복 | 강아지 | 하루하루의 만족 | 표정, 일상 사건의 분위기 |
| 유대 | 강아지 | 견주와의 신뢰 | 훈련 성공률, 위기 때 결과 |
| 사회성 | 강아지 | 다른 개·사람과 어울림 | 산책·여행·새 식구 적응 |
| 여유 | 가정 | 견주의 시간·마음·살림의 여유 | 병원 선택지, 새 식구 들이기, 여행 |

"여유"는 돈 액수를 보여 주지 않는 추상 수치다. 병원비 같은 현실 고민은 다루되 숫자로 된
돈은 쓰지 않는다.

### 4.4 생애 단계

견종 체급에 따라 늙는 속도가 다르다. 소형견은 늦게, 대형견은 일찍 노견이 된다.

| 단계 | 소형견 | 대형견 | 주요 사건 |
| ---- | ------ | ------ | --------- |
| 아기 | 0~1살 | 0~1살 | 배변 훈련, 예방접종, 첫 산책, 사회화 |
| 청년 | 1~3살 | 1~2살 | 중성화 결정, 사고뭉치 사건, 훈련 |
| 어른 | 3~8살 | 2~6살 | 여행, 이사, 견주 생활 변화, 새 식구 |
| 시니어 | 8~11살 | 6~8살 | 정기 검진, 견종별 질환, 식단 |
| 노견 | 11살~ | 8살~ | 시력·청력, 인지 저하, 느린 산책, 이별 준비 |

### 4.5 끝

- 수명은 견종의 기대 수명 범위 안에서 건강 수치와 사건에 따라 정해진다.
- 마지막은 늘 **무지개다리**다. 장면 묘사는 하지 않고, 이야기 흐름에 맞는 문장으로 담담히
  마무리한다. 예: "보리는 가장 좋아하던 담요 위에서 편안하게 잠들었어요."
- 그 뒤 **견생 기록 카드**가 나온다(8장).

## 5. 이야기 흐름(톤) 시스템

판을 시작할 때 아래 흐름 중 하나를 무작위로 고른다. 각 사건 카드에는 톤 태그(유쾌, 잔잔,
뭉클)가 붙어 있다. 흐름은 견생 진행률(0~100%)에 따라 어떤 톤의 사건이 뽑힐지 가중치를
바꾼다.

| 흐름 | 초반 | 중반 | 후반 | 이별 장면 |
| ---- | ---- | ---- | ---- | --------- |
| 끝까지 유쾌 | 유쾌 | 유쾌 | 유쾌 | 밝고 짧게("강아지별로 소풍 갔어요") |
| 유쾌하다 뭉클 | 유쾌 | 유쾌·잔잔 | 뭉클 | 따뜻하고 길게 |
| 잔잔하고 뭉클 | 잔잔 | 잔잔 | 뭉클 | 담담하게 |
| 뭉클하다 유쾌 | 뭉클(구조·적응) | 유쾌 | 유쾌·잔잔 | 감사로 마무리 |

- 흐름 이름은 결말 카드에 "이번 견생은 「웃다가 찡」이었어요"처럼 공개해 다시 하고 싶게 만든다.
- 같은 사건도 톤별로 문장을 다르게 쓸 수 있다(사건 하나에 문장 변형 여러 개).

## 6. 견종 데이터

### 6.1 원칙

- 수명, 체급, 잘 알려진 건강 경향은 **일반적인 경향을 단순화**해 반영한다.
- 화면에 "견종별 수치는 재미를 위해 단순화한 경향이며 수의학적 조언이 아닙니다"를 표시한다.
- 성격 키워드에 "사나움" 같은 부정적 고정관념을 쓰지 않는다. 성격은 견종보다 개체 성격
  2가지가 더 크게 작용한다.
- 등장 가중치는 국내 동물등록 비율을 대략 따른다. 2026년 413만 마리 분석에서 믹스견 19.9%,
  말티즈 17.1%였다([데일리벳](https://www.dailyvet.co.kr/news/college/294722)).
  구현 전에 농림축산검역본부 공공데이터로 한 번 더 맞춘다.

### 6.3 밈 견종과 별칭

밈 견종은 독립 견종이 아니라 **믹스견·진돗개 위에 붙는 별칭**으로 다룬다. 수치는 바탕 견종을
따르고, 이름과 소개 문구, 전용 사건으로 개성을 준다.

| 별칭 | 붙는 조건 | 소개 문구 예시 |
| ---- | --------- | -------------- |
| 시고르자브종 | 시골 마당 경로의 믹스견 | "혈통서는 없지만 마당 서열은 1위. 유서 깊은 시고르자브종이에요." |
| 진도믹스 | 진돗개 피가 섞인 믹스견 | "눈빛은 진돗개, 애교는 반반." |
| 백구·황구·흑구·바둑이 | 진돗개·믹스견의 털색 | "누가 봐도 황구. 해 질 녘에 보면 더 예뻐요." |
| 골댕이 | 골든 리트리버 | "세상 모든 사람을 친구라고 믿는 골댕이." |
| 말티푸 | 말티즈 × 푸들 | "말티즈의 애교와 푸들의 곱슬을 반씩." |

- "똥개"처럼 낮춰 부르는 말은 쓰지 않는다.
- "시고르자브종"의 어원은 확인되지 않았다. 게임 안에서는 시골 믹스견을 아끼는 애칭으로만
  쓴다. 밈 별칭 목록은 개발자 검수를 거쳐 늘린다.

## 7. 사건 카드

### 7.1 구조

사건은 데이터로 관리한다. 사건 하나는 다음 정보를 가진다.

```ts
type EventCard = {
  id: string;
  stage: LifeStage[];            // 나올 수 있는 생애 단계
  tones: Tone[];                 // 유쾌 · 잔잔 · 뭉클
  when?: Condition;              // 견종 경향, 성격, 능력치, 다견 여부, 이전 사건
  text: string[];                // 같은 사건의 문장 변형 (톤별 가능)
  choices?: Choice[];            // 없으면 일상 문장으로만 지나간다
  once?: boolean;
};

type Choice = {
  label: string;
  outcomes: { weight: number; text: string; effects: StatDelta; next?: string }[];
};
```

- 결과는 `weight`와 능력치로 확률이 정해진다.
- **금지 규칙은 테스트로 강제한다.** 모든 선택지는 강아지를 돌보는 선택이어야 하고, 파양·유기·
  학대·방치를 뜻하는 선택지가 데이터에 들어가면 테스트가 실패한다.

### 7.2 사건 분류와 첫 판 목표 수

| 분류 | 예시 | 목표 수 |
| ---- | ---- | ------- |
| 일상 | 우다다, 간식 도둑, 산책길 첫 눈, 택배 아저씨와의 전쟁 | 25 |
| 성장 | 배변 훈련, 예방접종, 사회화, 중성화 시기 | 10 |

### 7.3 선택 카드 예시

모든 선택지는 "무엇이 이 아이에게 더 좋을까" 사이의 고민이다.

**중성화, 언제 할까?** (청년기, 잔잔)
- 수의사와 상의해서 지금 하기 → 건강 +, 이번 달 행복 −
- 1년 더 지켜보고 결정하기 → 다음 해 다시 등장
- 다른 병원 의견도 들어 보기 → 여유 −, 다음 달 결과

**마당 있는 집으로 이사 갈까?** (어른기, 가족)
- 마당 있는 시골집 → 행복 ++, 사회성 −(동네 친구와 이별), 시고르자브종 이웃 사건 열림
- 익숙한 동네에 남기 → 유대 +, 산책 친구 사건 유지

**둘째를 들일까?** (어른기, 다견, 여유 50 이상일 때)
- 보호소의 노견을 입양하기 → 뭉클 사건 열림, 노견 둘째 생성
- 시골 마당에서 태어난 새끼 데려오기 → 시고르자브종 둘째 생성
- 지금은 첫째에게 집중하기 → 유대 +

**슬개골이 안 좋대요** (시니어기, 건강, 소형견 경향)
- 수술하기 → 여유 −−, 회복 뒤 건강 +
- 체중 관리와 근육 운동부터 → 성공 확률은 유대·성격에 따라
- 계단 대신 경사로 설치하기 → 여유 −, 악화 확률 −

### 7.4 안락사 선택지

- **나오는 조건은 모두 충족해야 한다.** 노견 단계, 치료할 수 없는 병(말기 종양, 말기 신부전
  같은 "불치" 표시가 붙은 사건)이 진행 중, 건강 수치가 기준 아래.
- 이 조건 밖에서는 어떤 사건에도 나오지 않는다. 데이터 검증 테스트로 강제한다
  (`euthanasia` 표시가 붙은 선택지는 위 조건을 가진 사건에만 허용).
- 선택지는 둘 다 돌봄으로 존중한다. 어느 쪽을 골라도 능력치 벌점이나 "잘못된 선택" 같은 평가가 없다.
  - 수의사와 상의해 편안하게 보내 주기
  - 남은 시간을 집에서 함께 돌보기
- 장면은 묘사하지 않는다. 결과 문장은 짧고 담담하게, 강아지가 편안했다는 데 초점을 둔다.
- 결말 카드에 "마음이 힘들 땐 가까운 사람과 이야기 나눠 보세요" 같은 짧은 문장을 둘지는
  구현 때 문장 검수와 함께 정한다.

## 8. 다견가정

- 첫째가 1살이 넘고 "여유"가 충분하면 새 식구 사건이 열린다. 견생에서 최대 두 번, 최대 3마리.
- 새 식구도 만남 뽑기 규칙으로 견종·성격·만난 나이를 정한다.
- 강아지끼리 **사이** 수치(0~100)가 생긴다. 첫 대면, 서열, 함께 하는 사고·놀이 사건에 쓰인다.
- 한 판은 **첫째의 견생**을 기준으로 끝난다. 그래야 다견가정이어도 10~15분을 지킬 수 있다.
  - 첫째가 무지개다리를 건너면 "남은 아이들의 이야기"를 빠르게 요약해 보여 준다.
  - 첫째보다 먼저 떠나는 둘째·셋째도 있을 수 있다. 그 아이의 기록 카드도 따로 남긴다.

4단계 구현 메모(2026-10-26):

- 새 식구 사건은 셋이다. "새 식구를 들여 볼까요?"(보호소의 나이 지긋한 아이 / 시골 마당 새끼 /
  지금은 집중), "비 오는 날 만난 강아지"(구조), "아는 분 댁 아기 강아지"(지인 분양). 모두 집에
  한 번만 일어나고, 언제나 들이지 않는 선택지가 있다.
- 열리는 조건: 그 아이와 함께한 지 1년 이상, 여유 50 이상(지인 분양은 55). 새 식구 사건은
  들였든 아니든 **견생에서 두 번까지**, 앞의 사건과 2년 넘게 떨어져서 열린다. 판이 끝났거나
  셋이 함께 살면 열리지 않는다. 이 규칙은 엔진이 지킨다.
- 들이기로 하면 "OO네 새 식구" 카드가 뜨고 시간이 멈춘다. 만남 카드와 같은 내용(그림·견종·소개·
  성격)에 이름 짓기가 붙는다. 가족과 같은 이름은 쓸 수 없고, 추천 이름에도 나오지 않는다.
  자동 결정이 켜져 있으면 잠시 뒤 첫 추천 이름으로 정한다. 이름을 고르거나 입력하면 기다린다.
- 다음 달에 첫 대면 선택 카드가 온다. 그 뒤로 두 아이 사건(밥그릇 신경전, 산책 속도, 합동 사고,
  줄다리기, 등 맞대고 낮잠, 질투, 동네 안내, 곁 지키기)이 일어난다. 사건 문장의 짝은 `{other}`로 쓴다.
- **사이**(0~100)는 두 아이마다 생긴다. 처음에는 두 아이의 사회성과 새 식구의 나이로 정하고,
  함께 지낼수록 사회성·성격에 따른 기준으로 천천히 다가간다. 가장 가까운 사이가 좋으면 행복이
  조금 오르고 나쁘면 조금 내려간다.
- 함께 사는 아이가 늘면 여유가 돌아가는 기준이 한 아이당 5씩 낮아지고, 선택 카드 사이 간격이
  한 아이당 3개월씩 넓어진다(고를 사건이 늘어나 카드가 너무 잦아지지 않게).
- 가족 일(이사·이직·아기·여행)은 강아지마다가 아니라 집에 한 번 일어난다.
- 아이가 떠나면 남은 아이들이 다음 달부터 차례로 그 아이를 그리워하는 사건이 온다.
- 첫째가 떠나면 판이 끝나고, 남은 아이들의 견생은 자동 결정으로 빠르게 이어 본다. 결말 화면의
  "함께한 가족"에 둘째·셋째의 기록 카드(먼저 떠난 아이 / 남은 아이의 이야기)가 나오고,
  "이야기 전체 보기"에 "남은 아이들의 이야기"가 붙는다.
- 진행 화면 위에 가족 탭이 생겨 아이마다 그림·능력치·사이를 볼 수 있다. 견생 지도는 첫째 기준이다.
- 2,000판(자동 결정) 기준: 한 마리 37% · 두 마리 52% · 세 마리 10%. 선택 카드 중간값 16번
  (한 마리 13번, 여럿 18번). 첫째와 함께한 시간 중간값 165개월로 1~3단계와 같다. 첫째보다
  먼저 떠나는 아이가 있는 판 21%, 남은 아이가 있는 판 45%(첫째를 보낸 뒤 중간값 5년 3개월).
  함께 사는 동안 일상 사건의 18%가 두 아이 사건이다. 견생 지도 색 분포는 그대로다.
- 저장 형식이 바뀌어(버전 2) 3단계 때 저장한 진행 중인 판은 이어 보기에 나오지 않는다.

  막힌 환경에서는 안내를 띄운다. 속도와 자동 결정 설정도 기기에 기억한다.

### 9.2 문장 쓰는 방식

- 견주 이름을 받지 않으므로 견주를 부르지 않는다. "보리가 현관에서 꼬리를 흔들며 기다렸어요"처럼
  강아지를 주어로 쓰고, 견주는 "우리"나 생략으로 처리한다.
- 선택 카드의 질문만 견주에게 말을 건다. 예: "중성화, 언제 할까요?"
- 묘사 수위는 처음부터 낮게 잡는다. 아픔·사고·이별은 결과만 짧게 쓰고 과정은 묘사하지 않는다.

## 10. 저장과 공유

- `localStorage`에 **진행 중인 판**(이어하기)과 **지난 견생 10건**을 저장한다. 서버로 보내지 않는다.
- 결말 카드는 Canvas로 PNG를 만들어 내려받는다. 지원하는 기기에서는 Web Share API로 바로 공유한다.
- 공유 카드에는 강아지 이름과 견종 정보만 들어간다. 개인 정보는 받지 않는다.
- 저장이 막힌 환경(시크릿 모드 등)에서는 로또쇼처럼 "기록이 유지되지 않을 수 있어요"를 띄운다.

5단계 구현 메모(2026-10-26):

- 판이 끝나면 지난 견생(`songiland:gyeonsaeng:lives`)에 판 상태를 그대로 옮기고 진행 중인 판은
  지운다. 같은 판(시드)은 한 번만 남고, 최근 10편까지만 둔다. 저장 공간이 모자라면 오래된
  견생부터 덜어 낸다.
- 시작 화면 아래 "지난 견생" 목록(얼굴 그림, 이름, 견종, 함께한 시간, 상영작 이름, 날짜)에서
  하나를 누르면 그 결말 카드와 이야기 전체를 다시 볼 수 있다.
- 공유 카드는 1080×1350 PNG(인스타그램 피드 4:5)다. 결말 화면이 열릴 때 미리 그려 둔다.
  - 담는 것: 상영작 이름, 강아지 그림, 이름, 견종·털색, 함께한 가족 이름, 함께한 시간·만난 곳·나이,
    기억에 남는 순간 3개, 견생 지도, `dog.arosys.kr`
  - 그림은 결말 화면의 SVG를 그대로 캔버스에 옮긴다. 글꼴은 화면과 같은 시스템 글꼴을 쓴다.
- `이미지로 저장`은 `견생극장-이름.png`로 내려받는다. 이미지 파일 공유를 지원하는 기기(주로
  휴대폰)에서만 `공유` 버튼이 보이고 공유 시트를 연다. 공유 시트는 버튼을 누른 직후에만 열리는
  브라우저가 있어 이미지를 미리 만들어 둔다.

## 11. 기술 구성

- 새 앱: `apps/dog`, 주소 `dog.arosys.kr`. 카탈로그 `kind: 'game'`, 포트 5176/4176.
  카탈로그 등록은 6단계에서 한다.
- 의존성은 React만 쓴다. 새 라이브러리는 추가하지 않는다.
- **시뮬레이션 엔진은 순수 TypeScript**로 분리한다. 시드가 있는 난수 생성기를 써서 같은 시드면
  같은 견생이 나오게 한다. 테스트와 버그 재현이 쉬워진다.
- 사건·견종·별칭은 데이터 파일로 두고, 데이터 검증 테스트를 둔다.
  - 모든 사건의 단계·톤·다음 사건 참조가 유효한지
  - 금지 선택지가 없는지
  - 견종 가중치·수명 범위가 말이 되는지
- 진행 타이머는 `requestAnimationFrame`이나 `setInterval`이 아니라 경과 시간 기반으로 계산해
  탭을 오래 비워도 몰아서 진행되지 않게 한다(탭이 숨겨지면 자동 일시정지).
- 테스트: 엔진 단위 테스트(시드 재현, 수명 범위, 다견 종료 규칙), 컴포넌트 테스트, e2e 1~2개
  (만남 → 4배속 → 결말 카드).

### 11.1 배경음악

**첫 출시에는 넣지 않기로 했다(2026-10-25).** 나중에 넣는다면 **곡마다 라이선스를 기록**하고,
기본값은 꺼짐(소리 끔)으로 둔다.

## 12. 윤리·법적 점검

- 돈·포인트·상품이 없으므로 사행성과 거리가 멀다.
- 파양·유기·학대·방치 선택지 금지는 데이터 테스트로 강제한다.
- 펫숍 구매 경로가 없다. "사지 말고 입양하세요" 같은 설교 문구도 넣지 않는다. 만남 경로 자체가
  메시지를 대신한다.
- 질병은 이름과 결과만 담담히 다룬다. 수술·고통 장면은 묘사하지 않는다.
- 안락사는 노견이고 치료할 수 없는 병일 때만 선택지로 나오며, 어느 선택도 평가하지 않는다(7.4).
- 묘사 수위를 처음부터 낮게 잡고, "무서운 장면 빼기" 토글은 첫 출시에 두지 않는다.
- 견종 건강 경향에는 "수의학적 조언이 아님" 안내를 붙인다.
- 그림과 글은 모두 자체 제작한다. 실존 브랜드·사료·병원 이름을 쓰지 않는다.

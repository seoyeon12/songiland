# Songiland

## Local development

Use the existing pnpm dependencies to run the app:

```bash
pnpm run dev
```

Run the available checks with `pnpm run test`, `pnpm run typecheck`, and `pnpm run build`.

## Scope

This initial shell exposes only the Songiland landing page at `/` and the first-game route at `/games/lotto`. The lotto route is a temporary placeholder until the game feature is implemented.
